# SLIPSTREAM → 0.7.0: Геймплейная уникальность, перки машин и Дуэли с Призраком

План переработки игрового ядра и добавления асинхронных челленджей на базе архитектуры `0.6.0`.

Ограничения проекта (сохраняем полностью):
- **Ноль внешних ассетов.** Вся графика — процедурный рендеринг (`_draw()`, `Fx`, `Art`, `RaceArt`, `StyleBoxFlat`), весь звук — синтез в `Sfx`.
- **GL Compatibility.** Без тяжёлых пост-шейдеров, стабильный FPS на мобильных Android-устройствах.
- **Полная обратная совместимость тестов.** Существующие регрессионные проверки (`RaceRegression`, `RewardsRegression`, `fixes_regression`) должны оставаться зелёными, включая детерминированность начислений и частоту частиц на 30/60/120/144 FPS.

## Этап 1. Взрывное ядро: «Рогатка» (Slingshot Draft) + «Хроно-щит» (Chrono-Shield)

**Задача:** сделать механику *Slipstream* главным источником адреналина, а механику перемотки времени — частью основного геймплея.

- [x] **Рогатка (Slingshot Draft):**
  - В воздушном мешке (`slip > 0.30`) вокруг машины игрока заряжается дуга Рогатки (бирюзовый → золотой при готовности).
  - Резкое перестроение (`move_lane`) при полном заряде (включая окно `0.45 с`) запускает **Выстрел из мешка (Slingshot Snap)**: рывок скорости (`×1.32` на `0.85 с`), `+0.25` (`0.75 * NITRO_SEG`) заряда нитро, `+1` к комбо и бонус очков (`80 × комбо`).
  - Отдельный звук готовности и выстрела рогатки в `Sfx`, визуальные дуги энергии вокруг машины и подсказка в HUD.
- [x] **Хроно-щит (Chrono-Shield Rewind):**
  - Запись короткого буфера кадров перемотки (`rewind_frames`) активна и в обычных заездах.
  - Накопленные 3 заряда нитро (`nitro >= 1.0`) формируют вокруг машины визуальный Хроно-щит (и индикатор `ЩИТ` на кнопке нитро).
  - При фатальном столкновении вместо конца заезда тратятся 3 заряда нитро, запускается перемотка назад и даётся короткая неуязвимость (`1.6 с`).

## Этап 2. Живой поток и дорожные события

**Задача:** убрать ощущение «рельсового» трафика и добавить смену ритма на трассе.

- [x] **Трафик с поворотниками:**
  - Попутные легковые машины, внедорожники, спорткары и пикапы могут перестраиваться между полосами.
  - Перед манёвром машина `1.25 с` мигает оранжевым поворотником и рисует маркер перестроения.
  - Жёсткая проверка безопасности: машина не перестраивается, если это создаёт глухую стену по всем 4 полосам в полосе видимости.
- [x] **Дорожные события (Road Events):**
  - **Радар скорости / Камера тихого хода:** рамка с лазерной линией и целевым условием (`ПРОБЕЙ X+ КМ/Ч` или `СБРОСЬ ДО 175 КМ/Ч`). Успешный проезд даёт вспышку, `+25` монет и `+300` очков.
  - **Зона дорожных работ:** временное сужение крайней полосы (конусы, мигающие маячки, барьер) на участке трассы с множителем очков `×2`.
  - **Блэкаут / Ночной коридор:** кратковременное отключение уличных фонарей с усиленным фокусом на фарах и множителем очков `×2`.

## Этап 3. Уникальные способности 9 машин (`cars.gd`, `game.gd`, Гараж)

**Задача:** превратить машины гаража из косметических вариантов в 9 разных стилей игры.

- [x] **HATCH (`compact`):** *Юркий кузов* — хитбокс уже на `12%`, легче уходить от касаний.
- [x] **VAN (`taxi_magnet`):** *Магнит и тариф* — повышенная максималка (`1090`), притягивает монеты с соседней полосы и даёт `+35%` монет за заезд.
- [x] **SEDAN GT (`wide_cutin`):** *Мастер подреза* — увеличенное окно и дистанция cut-in (`+45%` окно, `+25%` нитро).
- [x] **OFF-ROAD (`all_weather`):** *Вездеход и люстра* — лужи в дождь заряжают нитро и дают очки, дальняя LED-балка заставляет трафик уступать полосу.
- [x] **MUSCLE (`ram_nitro`):** *Таран на нитро* — при активном нитро таранит одну легковую машину без аварии (`+250` очков и сноп искр).
- [x] **PICKUP (`extra_tank`):** *4-й баллон нитро* — ёмкость нитро увеличена до 4 сегментов (старт с 2 зарядами; можно держать 3 заряда на Хроно-щит + 1 для буста).
- [x] **SPORT (`carbon_brakes`):** *Карбон и аэро* — тормоза греются на `45%` медленнее, остывают на `35%` быстрее, Рогатка заряжается на `35%` быстрее.
- [x] **VOLT EV (`regen_brake`):** *Рекуперация* — торможение на скорости заряжает шкалу нитро (`+0.28 / с`).
- [x] **HYPER (`hyperdrive`):** *Гипердрайв* — на скорости свыше `310 км/ч` активируется аура гипердрайва (`×2` очков за дистанцию и обгоны).
- [x] **Гараж UI:** отображение плашки особенности класса для каждой машины.

## Этап 4. Асинхронный «Вызов друга» (Ghost Duel по коду) и «Вызов дня»

**Задача:** дать соревновательный режим с другом через мессенджер без серверов и аккаунтов.

- [x] **Детерминированный заезд (`run_rng`):**
  - Выделен генератор трафика, предметов, погоды, свободной полосы и дорожных событий в `run_rng` с явным `seed`.
  - Сохраняются `seed`, стартовое время суток и погода каждого заезда.
- [x] **Кодек Вызова и Призрак (`ChallengeCodec`, `challenge.gd`):**
  - Запись траектории игрока (позиция по дороге `scroll`, поперечная координата `x`, флаги тормоза/нитро/рогатки) с шагом `0.20 с` (с адаптивным уплотнением для длинных заездов).
  - Сжатие `COMPRESSION_DEFLATE` + Base64URL с контрольной суммой → компактный код `SLIP1-...`.
  - Автоматический парсинг кода из произвольного текста (например, сообщения из Telegram).
- [x] **Живой Призрак на трассе (`game.gd`):**
  - Полупрозрачный голографический силуэт машины соперника с обводкой, ником, отрывом/отставанием в метрах (`+12 м` / `-45 м`) и стрелками-маркерами при выходе за экран.
  - Голографическая черта места аварии соперника на дороге.
- [x] **Ежедневный вызов (Daily Challenge):**
  - Общий для всех игроков заезд на основе даты (`YYYY-MM-DD`) с фиксированной машиной (выдаётся бесплатно на попытку), погодой и тремя целями (Бронза / Серебро / Золото) с одноразовой наградой в монетах в день.
- [x] **Интерфейс Вызовов (`main.gd`):**
  - Экран **«ВЫЗОВЫ»** из главного меню (Вызов дня, Вставить код друга из буфера, превью вызова, смена ника).
  - Кнопки **«ВЫЗВАТЬ ДРУГА (КОД)»** и **«ОТПРАВИТЬ РЕВАНШ (КОД)»** на экране финиша с копированием готового текста в буфер обмена.
